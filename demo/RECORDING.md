# Demo video — how it was recorded

`demo-video.mp4` — 91 seconds, 1280×900, H.264, no audio. Title card (4s) +
simulator screen recording (83s) + end card (4s). Under the 3-minute limit.

## Reproduce

```bash
# 1. Dev server + simulator running (Xvfb on :99, automation port 9898)
npm run dev
npm run simulate

# 2. Record the X display (no mouse cursor in the frame)
DISPLAY=:99 ffmpeg -y -f x11grab -draw_mouse 0 -framerate 30 -s 1280x900 \
  -i :99 -c:v libx264 -preset veryfast -crf 23 -pix_fmt yuv420p \
  /tmp/perpwatch-demo-raw.mp4 &

# 3. Drive the app (slow journey with holds per screen)
python3 scripts/demo-journey.py

# 4. Stop the recording (SIGINT so ffmpeg finalizes the file)
kill -INT <ffmpeg-pid>

# 5. Assemble with the title/end cards
ffmpeg -y -framerate 30 -loop 1 -t 4 -i demo/title-card.png \
  -i /tmp/perpwatch-demo-raw.mp4 \
  -framerate 30 -loop 1 -t 4 -i demo/end-card.png \
  -filter_complex "[0:v]fps=30,format=yuv420p[t0];[1:v]fps=30,format=yuv420p[t1];[2:v]fps=30,format=yuv420p[t2];[t0][t1][t2]concat=n=3:v=1:a=0[v]" \
  -map "[v]" -c:v libx264 -preset veryfast -crf 23 -r 30 demo/demo-video.mp4
```

Cards are generated by `scripts/make-cards.py` (PIL + DejaVu fonts).

## What the video shows

Home positions list → ETH detail → 24h sparkline chart → LIT detail (no liq
price) → prices → funding → home. All live Hyperliquid data from the public
demo address. The companion settings page is visible on the left of the
simulator window throughout.
